# Mission Life

A mobile app that turns daily goals into an RPG. Create a character, set missions, and every real-life task done takes HP off a monster. XP unlocks levels and trophies.

**Live demo (web, mock data):** https://chatthadasainoi-cmyk.github.io/portfolio/demo/missionlife/ · sign in with `demo` / `demo1234`

Team project, Scripting Languages Project course (1101103), group 09.

## Features
- Sign-up, sign-in and password reset by email OTP
- Quests, mission battle against a monster, trophies and history
- Step-by-step Create Mission and Create Monster flows
- Admin web app for managing content

## Tech stack
React Native · Expo · Firebase Firestore · Node.js · MongoDB · Figma

## Repository layout
- `user/my-app`: the mobile app
- `Admin/`: admin frontend and backend
